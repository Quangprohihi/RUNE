# VietQR + Manual-Confirm Payment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a VietQR bank-transfer payment method (admin manually confirms) alongside the existing VNPay flow so a personal MSB account takes real money for the demo.

**Architecture:** A new `provider: 'vietqr'` `PaymentOrder` reuses the existing `vnpTxnRef` field as the bank-transfer content and the existing `adminConfirmOrder` cascade for activation. Backend adds a pure QR-URL builder + one create endpoint; the app adds a QR screen reached from a payment-method chooser; VNPay and all historical orders are untouched.

**Tech Stack:** Backend — Express 5 + Prisma 7 + vitest. App — Flutter (package `rune`) + provider. Admin — React + Vite.

## Global Constraints

- Do NOT remove VNPay or modify any historical `payment_orders` rows.
- No DB schema migration — `provider` and `vnpTxnRef` already exist on `PaymentOrder`.
- Bank config lives in env, never hardcoded: `VIETQR_BANK_BIN`, `VIETQR_ACCOUNT_NO`, `VIETQR_ACCOUNT_NAME`, `VIETQR_BANK_NAME`.
- MSB demo values: BIN `970426`, account `6102062004`, name `VU NGOC QUANG`, bank `MSB`.
- Transfer content = the order's `vnpTxnRef` (plain numeric, as generated by `createTxnRef`).
- Backend tests run with `npm test` (vitest) from `backend/`. App tests run with `flutter test`.

```ts
// backend/src/services/vietqr.service.ts
function requiredEnv(name: string) {
  const value = process.env[name];
  if (!value) {
    throw Object.assign(new Error(`${name} is not configured`), { status: 500 });
  }
  return value;
}

export function getVietqrConfig() {
  return {
    bankBin: requiredEnv('VIETQR_BANK_BIN'),
    accountNo: requiredEnv('VIETQR_ACCOUNT_NO'),
    accountName: requiredEnv('VIETQR_ACCOUNT_NAME'),
    bankName: requiredEnv('VIETQR_BANK_NAME'),
  };
}

export function buildVietQrImageUrl({
  amountVnd,
  addInfo,
}: {
  amountVnd: number;
  addInfo: string;
}) {
  const { bankBin, accountNo, accountName } = getVietqrConfig();
  const params = new URLSearchParams({
    amount: String(amountVnd),
    addInfo,
    accountName,
  });
  return `https://img.vietqr.io/image/${bankBin}-${accountNo}-compact2.png?${params.toString()}`;
}
```

```ts
export async function createVietqrPaymentOrder({
  productCode,
  userId,
}: {
  productCode: string;
  userId: string;
}) {
  const product = await getProduct(productCode);
  const txnRef = createTxnRef();
  const order = await prisma.paymentOrder.create({
    data: {
      userId,
      provider: 'vietqr',
      productType: product.productType,
      productCode: product.productCode,
      amountVnd: product.amountVnd,
      currency: 'VND',
      status: 'pending',
      vnpTxnRef: txnRef,
    },
  });

  const { accountNo, accountName, bankName } = getVietqrConfig();
  const qrImageUrl = buildVietQrImageUrl({
    amountVnd: product.amountVnd,
    addInfo: txnRef,
  });

  return {
    orderId: order.id,
    qrImageUrl,
    bankName,
    accountNo,
    accountName,
    amountVnd: product.amountVnd,
    transferContent: txnRef,
  };
}
```

```dart
      if (!mounted) return;

        SnackBar(content: Text('Could not start VNPAY payment: $error')),
```
